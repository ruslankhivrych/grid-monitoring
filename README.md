# Felicity Grid Telegram Bot

Репозиторій містить лише Telegram-бота для моніторингу електромережі через хмарний
сервіс FSolar. Бот опитує інвертор, показує стан мережі й батареї та надсилає
сповіщення про зникнення або відновлення живлення.

## Можливості

- команди `/status`, `/battery`, `/stats`, `/history`, `/outages`, `/charts`, `/start`, `/stop` і `/menu`;
- статистика споживання зараз та за день, місяць, рік і весь час;
- потужність і напрям заряджання або розряджання акумулятора;
- автоматичні сповіщення на порогах SOC 90%, 50%, 25% при розряджанні та 90%, 99%
  при заряджанні;
- постійне меню Telegram;
- сповіщення про відсутність свіжої телеметрії понад 15 хв та відновлення зв’язку;
- тривалість відключень і зміна заряду, статистика за день та місяць (`/outages`);
- графіки заряду й навантаження за 24 години, 7 і 30 днів (`/charts`);
- фонове опитування FSolar з автоматичним повторним входом після завершення токена;
- сповіщення лише при зміні стану мережі;
- SQLite-історія, підписки й персистентна черга доставки;
- запуск через Docker Compose або Python 3.12;
- CI-перевірка синтаксису та тестів.

## Структура

```text
bot/
  src/
    bot.py       Telegram-команди й фоновий полер
    config.py    конфігурація зі змінних середовища
    detector.py  визначення переходу стану мережі
    fsolar.py    клієнт FSolar і мапінг телеметрії
    monitoring.py свіжість даних та облік відключень
    charts.py    графіки заряду й навантаження
    storage.py   SQLite-сховище та черга Telegram-повідомлень
  tests/         автоматичні тести
  Dockerfile
  docker-compose.yml
  .env.example
docs/
  fsolar-api.md  відомий контракт приватного FSolar API
scripts/
  verify-api.ps1 ручна перевірка FSolar API
```

## Швидкий запуск

```bash
cd bot
cp .env.example .env
# заповніть TELEGRAM_BOT_TOKEN, FSOLAR_USERNAME, FSOLAR_PASSWORD і FSOLAR_DEVICE_SN
docker compose up -d --build
docker compose logs -f
```

На першому запуску можна тимчасово залишити `ALLOWED_CHAT_ID` порожнім і надіслати
боту `/start`: він покаже ваш chat ID, але не відкриє доступ до даних. Додайте цей ID
до `.env` і перезапустіть контейнер.

Повна інструкція з конфігурації та розгортання: [bot/README.md](bot/README.md).

## Перевірка

```bash
python -m pip install -r bot/requirements.txt pytest
python -m compileall bot/src
python -m pytest bot/tests -q
```

## Важливі обмеження

FSolar не надає стабільного публічного контракту для використаних endpoint-ів, тому
зміни їхнього веб-API можуть вимагати оновлення клієнта. Швидкість сповіщень також
обмежена частотою, з якою інвертор надсилає дані в хмару (зараз близько п'яти хвилин).
